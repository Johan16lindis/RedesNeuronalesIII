# Redes Neuronales III

## Descripción

Proyecto académico de Deep Learning desarrollado en Google Colab mediante Python, TensorFlow y Keras. Se estudian técnicas de optimización, regularización y evaluación de redes neuronales para clasificación de imágenes.

## Objetivo

Implementar y evaluar modelos de redes neuronales, analizando el efecto de los optimizadores, las técnicas de regularización y las métricas de clasificación.

## Tecnologías utilizadas

- Python
- Google Colab
- TensorFlow y Keras
- NumPy
- Matplotlib
- Scikit-learn

## Conjunto de datos

Fashion-MNIST, compuesto por imágenes en escala de grises de 28 × 28 píxeles distribuidas en diez clases.

## Prácticas desarrolladas

1. Preprocesamiento y distribución de datos.
2. Comparación de optimizadores SGD y Adam.
3. Regularización mediante Dropout y L2, Early Stopping y evaluación con métricas de clasificación.

## Ejecución

Los notebooks pueden abrirse en Google Colab. Cada archivo incluye el código, las instrucciones y las salidas de las prácticas.

## Resultados

Los resultados, gráficas y métricas se documentan en los notebooks y en el informe académico asociado al proyecto.
